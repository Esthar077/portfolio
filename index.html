Inside the engineering

Explore the challenges, engineering decisions and results behind my work.

Database credential migration · 2,000+ databases

Challenge

Replace shared database credentials without production downtime.

Approach

Automated PostgreSQL role provisioning, encrypted AWS Secrets Manager storage, credential rotation and connection validation using AWS Lambda.

Impact

Migrated more than 2,000 production databases.

Migration → Role provisioning → Secrets Manager → Validation
AI assistant for Microsoft Teams · RAG + Bedrock

Challenge

Help employees find internal knowledge without leaving Teams.

Approach

Built a single-tenant Teams app using AWS Lambda, knowledge-source routing, RAG, Amazon Bedrock and Adaptive Cards, with prompt caching, feedback and scheduled reports.

Outcome

Knowledge access directly inside Microsoft Teams.

Teams → Lambda → RAG + Bedrock → Adaptive Card
Audit logging framework · Multilingual templates

Challenge

Hard-coded audit descriptions were difficult to maintain and localize.

Approach

Implemented configurable templates, dynamic placeholders and structured change details.

Outcome

Separated audit message presentation from application code.

Audit event → Template → Placeholders → Localized log
